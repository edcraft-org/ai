\section*{Abstract}\phantomsection\addcontentsline{toc}{section}{Abstract}

Large language models (LLMs) can generate assessment questions with incorrect answers or faulty distractors. This project investigates a checking and revision workflow for reusable assessment templates, with Python tracing questions as the initial implementation. A model proposes a template and checking plan. The application runs selected checks through the Model Context Protocol (MCP) and returns failure evidence to guide revision. Property-based tests compare answer recipes with program execution and check that distractors remain incorrect and distinct over sampled inputs. Difficulty assessment forms part of the authoring workflow, while relevance assessment provides separate advisory feedback. Across fifteen distinct requests evaluated with three OpenAI models, feedback-guided revision produced thirty final candidates passing offline technical checks out of forty-five, compared with fourteen for one-shot generation and twenty-two for check-and-regenerate. Revision improved technical yield over one-shot generation, although its advantage over regeneration remained statistically inconclusive. Separate difficulty and relevance studies measured agreement with reference labels while validation against learner performance remains future work. Saved templates generate reproducible question variants locally without further model calls. The results support checking and revision for improving technical validity within the evaluated Python tasks, at the cost of additional inference and latency during authoring.
