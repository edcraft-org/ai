\section*{Abstract}\phantomsection\addcontentsline{toc}{section}{Abstract}

LLM-generated assessment questions can contain incorrect answers or distractors that coincide for some inputs. This project investigates a checking and revision workflow for reusable assessment templates, with Python tracing questions as the initial domain. A model proposes a template and checking plan. The application runs the selected checks through MCP and returns failure evidence for bounded revision. Property-based tests compare answer recipes with program execution and check that distractors remain incorrect and distinct over sampled inputs. Difficulty assessment supports the authoring workflow, while relevance assessment is available separately. Across fifteen requests evaluated with three OpenAI models, feedback-guided revision produced thirty final candidates passing offline technical checks out of forty-five, compared with fourteen for one-shot generation and twenty-two for check-and-regenerate. The advantage over regeneration remained statistically inconclusive. Final counts include candidates withheld from delivery. Separate difficulty and relevance studies measured agreement with project references; learner-based educational validation remains future work. Saved templates generate reproducible variants locally without further model calls. The results support technical checking and repair within the evaluated Python tasks, with additional inference and latency during authoring.
