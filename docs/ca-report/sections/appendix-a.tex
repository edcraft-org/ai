\section{Supporting comparison tables}\label{app:comparisons}

These tables provide supplementary material for the comparisons described in Sections~\ref{sec:evaluation-design}--\ref{sec:reuse}. Quality ratings are conditional model judgments. Upfront authoring costs include unsuccessful jobs, while generated batches may contain duplicate drafts.

Direct question generation produces individual questions and is used in the reuse study. The main authoring comparison instead uses one-shot template generation as its baseline.
